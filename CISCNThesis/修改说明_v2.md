## 主要修改

| 修改主题 | 旧版本的风险或不足 | V2 的修改 | 所在位置 |
|---|---|---|---|
| 方案层级 | 多个复杂模块同时出现，难以判断哪些是基础链路 | 明确“默认提交链路—候选增强—条件性临床模块”三级结构 | 研究背景、第一章 |
| 医学起点定义 | onset、早期募集和传播在部分表述中容易混为一谈 | 区分 UEO、最早明确电图变化、首批持续募集、临床 onset 与晚期传播；官方标注优先 | 第五章 5.1 |
| onset 循环依赖 | 动态基线依赖 onset，onset 又依赖动态图 | 改为两阶段推理：先用默认时域—时频链路粗定位，再在基线可靠时精修 | 第五章 5.2 |
| Top-10 含义 | 竞赛贡献度与临床早期通道评分混在同一排序中 | 拆分为 `S_comp` 和 `S_clinical`；默认提交使用竞赛贡献度，临床评分仅作附加分析 | 第六章 |
| SOZ、EZ 表述 | 容易让模型输出被理解为临床 SOZ/EZ 结论 | 明确模型候选通道、SOZ、EZ 和手术处理区不是同一概念，模型不能替代多学科判断 | 研究背景、临床责任边界 |
| 图方向解释 | “传播方向”“因果”措辞偏强 | 统一改为有向领先关系、统计外流或传播上游候选；不宣称观察数据已证明因果 | 第三、六章 |
| 模型选择 | 多指标同时列出但缺少唯一选择顺序 | 规定官方指标优先；官方指标未知时以患者级宏平均 PR-AUC 为主，onset、校准和 P95 时延作平局判据 | 第八章 |
| 数据泄漏控制 | 校准集与外层测试隔离描述不够具体 | 明确用患者级折外 logits 拟合校准器，外层测试患者不参与校准 | 第三、八章 |
| 通道遮挡 | 直接置零可能制造非生理阶跃 | 优先采用特征遮挡或基线/频谱匹配替换，并保留独立缺失掩码 | 第三、六章 |
| SiLU 与 SwiGLU | 未说明是否需要升级 | SiLU 保留为卷积主干默认；SwiGLU 仅在前馈子层做等参数消融，收益不稳则不用 | 第三、八章 |
| STFT 与小波 | 容易把小波替换理解为必然升级 | STFT/多分辨率 STFT 为正式基线；Morlet 仅作辅助消融，并注明不能恢复奈奎斯特频率以上信息 | 第三、八章 |
| HFO 使用边界 | HFO 容易被当作发作或 SOZ 的充分证据 | 增加采样率、滤波、伪迹和生理性 HFO 限制，不把单一 HFO 当充分证据 | 研究背景、第三章 |
| 可复现性 | 缺少从数据审计到冻结提交的执行阶段 | 新增里程碑、阶段产物、继续/停止条件和复现实验要求 | 第八章“实施计划与可复现性” |
| 文献依据 | 医学定义与指标缺少集中出处 | 新增 WHO、ILAE/临床综述、EI、cEI、HFO、EZ 和赛题页面等 9 条参考文献 | 参考文献 |
| 图示与排版 | 起点概念、两阶段流程不够直观；正文前存在多余分页 | 新增 onset 时间线和两阶段流程图，复用总体架构图，移除多余强制分页，并修正公式溢出与希腊字母缺字 | 第三、五章及版式 |

## 精确比较方法

在 `CISCNThesis` 目录运行：

```bash
git diff --no-index --word-diff=plain example.tex example_v2.tex
git diff --no-index --word-diff=plain seeg_solution_continuation.tex seeg_solution_continuation_v2.tex
git diff --no-index --word-diff=plain cumcmthesis.cls cumcmthesis_v2.cls
```

`git diff --no-index` 在发现差异时返回状态码 1，这是正常行为，不代表比较失败。

## LaTeX 编译方式

V2 是直接修改 LaTeX 源码得到的，不是对旧 PDF 进行编辑。入口文件为 `example_v2.tex`，并通过 `\input{seeg_solution_continuation_v2.tex}` 引入后续章节。

使用 XeLaTeX 编译三遍，以生成稳定的目录、引用和总页数：

```bash
xelatex -interaction=nonstopmode -halt-on-error example_v2.tex
xelatex -interaction=nonstopmode -halt-on-error example_v2.tex
xelatex -interaction=nonstopmode -halt-on-error example_v2.tex
```

所需的主要宏包包括 `ctex`、`geometry`、`amsmath`、`titlesec`、`tocloft`、`mdframed`、`algorithmicx`、`algorithms`、`pgf`、`hyperref` 和 `cleveref`。源文件统一使用 UTF-8 编码，并要求 XeLaTeX 编译，不使用 pdfLaTeX。
