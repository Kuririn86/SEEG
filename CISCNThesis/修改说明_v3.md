## V3 的目标

V3 不是增加更多技术，而是让评委能够迅速看懂“任务是什么、基础模型是什么、如何验证、最终输出什么”。正文从 V2 的 45 个物理页面缩减为 17 个物理页面，其中正式编号正文和附录为 12 页。

## 主要修改

| 主题 | V2 | V3 |
|---|---|---|
| 技术主线 | 默认链路、增强模块和临床模块交叉出现 | 只保留“预处理→时域卷积＋STFT→门控融合→TCN→四个输出头”一条基础链路 |
| 模型命名 | 强调 QST-DPGNet 和动态传播 | 淡化模型名称，首先解释数据如何流动和每个模块解决什么问题 |
| 高级模块 | 动态图、空间图、募集头占较多正文 | 动态图、Morlet、小波、坐标和脑区映射统一降为验证后或条件模块 |
| 公式说明 | 技术定义较密集 | 每个保留公式前后增加用途、变量含义和直观解释 |
| onset | 多个后处理和状态机制分散描述 | 统一为“滑窗融合→粗 onset→基线检查→可选精修→延迟校正” |
| Top-10 | 比赛解释分数与临床早期分数篇幅接近 | 正文只以模型贡献度作为正式 Top-10；临床早期通道仅作附加解释 |
| SOZ/EZ | 边界严谨但重复较多 | 在背景、Top-10 和术语表中用简短语言统一说明 |
| 实验设计 | 大型消融矩阵 | 改为 M0 至 M5 的顺序实验，每次只验证一个新增模块 |
| 可读性 | 研究论文式术语较多 | 使用短段落、任务对应表、术语速查和具体处理顺序 |
| 图示 | 模块密集，基础与可选链路不易区分 | 用 Python 重画总体模型图，分为默认主干、正式输出和模块边界三个面板 |

## V3 明确不作出的承诺

- 不声称动态图、小波或 SwiGLU 必然优于基础模型；
- 不声称模型 Top-10 就是 SOZ、EZ 或手术靶点；
- 不在缺少真实数据时写入患者数量、采样率分布或性能数字；
- 不把第一次状态概率超过 0.5 直接作为 onset；
- 不在基础链路中依赖可能缺失的坐标、影像和脑区标签。

## 编译方法

在 `CISCNThesis` 目录使用 XeLaTeX。总体模型图由 Python 直接生成，随后编译 onset 图和主文档：

```bash
python3 tmp/pdfs/seeg_figures_zh_final_v3/text_flow_with_placeholders_v1.py
xelatex -output-directory=tmp/pdfs/seeg_figures_zh_final_v3 tmp/pdfs/seeg_figures_zh_final_v3/onset-v3.tex
xelatex -interaction=nonstopmode -halt-on-error example_v3.tex
xelatex -interaction=nonstopmode -halt-on-error example_v3.tex
xelatex -interaction=nonstopmode -halt-on-error example_v3.tex
```

## 仍需赛题数据确认

1. 官方 onset 标注所对应的医学或操作性时间点；
2. Top-10 官方评分是否确实以模型贡献度为准；
3. 原始采样率、前端带宽、患者数量和通道数分布；
4. 官方综合指标、页面限制、推理硬件和时延计算方式；
5. 哪些模块在患者级实验中得到真实、稳定的提升。
