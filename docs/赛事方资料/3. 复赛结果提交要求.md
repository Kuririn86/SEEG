**复赛参赛选手操作指南**

结果提交要求

| **适用阶段** | **提交文件** |
| ------------------ | ------------------ |
| 复赛               | prediction.csv     |

**核心要求** 选手只需提交一个 prediction.csv。

# 1 提交流程

1. 按照测试集样本清单，为每个 sample_id 生成且仅生成一行预测。
2. 将预测结果保存为 UTF-8 编码的 prediction.csv。
3. 提交评分；

# 2 提交目录与文件命名

推荐的提交结构如下。文件夹内仅保留正式结果文件，避免放入缓存、临时文件或多个同名结果。

```
prediction.csv
```

- 文件名必须为 prediction.csv，大小写和扩展名均应保持一致。
- 评分器优先读取提交目录的 prediction.csv；若递归找到多个同名文件，提交将失败。
- 提交物不要包含可执行程序、脚本、模型文件或与评分无关的附件。

# 3 prediction.csv 格式

第一行为字段名，之后每一行对应一个测试样本。建议严格使用以下字段，不增加其他列：

```
sample_id,prob,decision_threshold,onset_time,ch1,ch2,ch3,ch4,ch5,ch6,ch7,ch8,ch9,ch10
```

| **字段**     | **类型** | **填写要求**                                                                             |
| ------------------ | -------------- | ---------------------------------------------------------------------------------------------- |
| sample_id          | 字符串         | 测试样本唯一标识。不得为空、不得重复，且必须与赛方发布的测试样本 ID 完全一致。                 |
| prob               | 浮点数         | 癫痫发作概率，范围为\[0, 1\]。AUC 直接使用该概率计算。                                         |
| decision_threshold | 浮点数         | 全局分类阈值，范围为\[0, 1\]。整份提交中的所有行必须填写同一个值。                             |
| onset_time         | 浮点数         | 预测发作起始时间，单位为秒，范围为\[0, 60)。所有行均须填写有限数值；预测为非发作时建议填 0.0。 |
| ch1-ch10           | 字符串         | 预测为发作时填写按重要性排序的 10 个通道名称。10 个值必须非空、互不重复，且真实存在于该样本。  |

# 4 分类与通道填写规则

评分器按下面的规则自动生成预测类别：

```
predicted_label = 1 if prob >= decision_threshold else 0
```

- 不得提交 label 列。即使 label 内容正确，只要文件包含该列也会被判定为格式错误。
- 当 prob ≥ decision_threshold 时，ch1-ch10 必须填写 10 个非空且不重复的有效通道名称。
- 当 prob < decision_threshold 时，ch1-ch10 可以留空，但 10 个字段名仍必须保留。
- **通道名称应直接取自对应样本的通道信息，保持字符、数字和大小写一致；不要使用自行编号或其他样本的通道。**
- 数值字段不得为空，也不得出现 NaN、Inf、-Inf 或无法解析为数字的文本。

# 5 样本覆盖与对齐要求

- prediction.csv 必须覆盖测试集全部 sample_id，不能缺少样本。
- 不能提交测试集之外的额外 sample_id。
- 每个 sample_id 只能出现一次；行顺序不限，评分器按 sample_id 对齐。
- 文件不能为空，且所有字段名应去除前后空格。
- 建议在导出后重新读取 CSV，检查列数、行数和编码，避免 Excel 自动改写 ID 或科学计数法。

# 6 评分指标与权重

总分范围为 0-1，平台结果文件保留 6 位小数。最终得分由以下指标加权得到：

| **指标** | **权重** | **说明**                                                                   |
| -------------- | -------------- | -------------------------------------------------------------------------------- |
| AUC            | 25%            | 使用真实类别与 prob 计算，评价概率排序能力。                                     |
| F1             | 15%            | 使用全局阈值生成的预测类别计算。                                                 |
| Sensitivity    | 10%            | 灵敏度/召回率，衡量真实发作样本的检出能力。                                      |
| Specificity    | 10%            | 特异度，衡量非发作样本的正确识别能力。                                           |
| Channel score  | 25%            | 评价真实发作样本的 Top-10 通道重合度与排序一致性。漏检发作时该样本通道得分为 0。 |
| Onset score    | 15%            | 根据发作起始时间平均绝对误差计算；漏检发作按 60 秒误差计。                       |

```
Score = 0.25×AUC + 0.15×F1 + 0.10×Sensitivity + 0.10×Specificity\+ 0.25×ChannelScore + 0.15×OnsetScore
**起始时间得分计算为：**OnsetScore = max(0, 1 − MAE_onset / 60)。
```


# 7 示例文件

以下仅用于说明格式，sample_id 和通道名称请替换为赛方实际发布的数据：

```
sample_id,prob,decision_threshold,onset_time,ch1,ch2,ch3,ch4,ch5,ch6,ch7,ch8,ch9,ch10
test_000001,0.8625,0.5000,12.4,A1,A2,A3,A4,A5,A6,A7,A8,A9,A10
test_000002,0.1200,0.5000,0.0,,,,,,,,,,
```


# 8 平台评分行为

选手确认提交后，平台在隔离环境中调用评分入口：

```
python script.py {submit_x} {result_file} {runtime_info_file}
```

- {submit_x}：平台上的选手提交目录，只读。
- {result_file}：评分脚本写入的最终得分文件，内容为一个浮点数。
- {runtime_info_file}：运行信息文件，记录样本数、各项指标或异常详情。

**异常处理** 文件缺失、字段缺失、样本不一致、数值越界、阈值不统一、通道无效等任一异常，均会中止本次评分；结果文件写入 0.000000，并在运行信息中记录错误原因。

# 9 常见失败原因

| **失败类型**      | **典型原因**                                                 |
| ----------------------- | ------------------------------------------------------------------ |
| 找不到 prediction.csv   | 文件名错误、未放在提交目录内，或文件结构异常。                     |
| 找到多个 prediction.csv | 文件夹中保留了备份、旧版本或嵌套副本。                             |
| 缺少字段                | 字段名拼写错误，或缺少 ch1-ch10 中任意一列。                       |
| 包含 label              | 预测类别必须由 prob 和 decision_threshold 自动生成。               |
| 样本无法对齐            | 缺少、增加或重复了 sample_id，或 ID 被表格软件改写。               |
| 阈值不统一              | 不同数据行填写了不同的 decision_threshold。                        |
| 数值非法                | prob/阈值超出\[0,1\]，onset_time 不在 \[0,60)，或含 NaN/Inf/空值。 |
| 通道校验失败            | 预测为发作的样本未填写满 10 个唯一有效通道，或通道不属于该样本。   |

# 10 提交前自检清单

- 文件名为 prediction.csv，且提交包中只有一个同名文件。
- 使用 UTF-8 编码，首行字段完整，未包含 label 列。
- 行数与测试样本数一致，sample_id 无空值、无重复、无增减。
- prob 和 decision_threshold 均在 \[0,1\]，且阈值全表一致。
- onset_time 全部为有限数值并位于 \[0,60)。
- 所有预测为发作的样本均填写了 10 个唯一、合法、顺序明确的通道名称。
- 结果文件夹直接包含 prediction.csv，不含隐藏文件、缓存或无关附件。
- 已用程序重新读取导出的 CSV，并确认列数、数据类型和特殊字符未被改写。
