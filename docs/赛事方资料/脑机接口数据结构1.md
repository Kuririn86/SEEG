# 脑机接口杯整合数据目录说明

# 基础信息

数据集按 `seeg_data_001`～`seeg_data_017` 拆分为 17 组资源。每组资源包含以下两类数据：

- `sample/`：调试阶段可见，存放训练样本及其标签。
- `formal/`：生产阶段可见，存放无标签测试样本。

| 数据角色               | 文件类型        | 文件总数 | 编号全集                           |   
| ---------------------- | --------------- | -------: | ---------------------------------- | 
| 样例数据（`sample`） | `train_*.npz` |      440 | `train_000001`～`train_000440` | 
| 正式数据（`formal`） | `test_*.npz`  |      924 | `test_000001`～`test_000924`   | 

> `sample` 中每个资源包都有独立的 `label.csv`，只包含该包内 `train_*.npz` 的标签；`formal` 中不提供标签。
