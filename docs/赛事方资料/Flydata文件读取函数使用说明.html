Flydata 文件读取函数使用说明

Flydata 通过 FlyData 类提供以下两个文件读取方法：

  • load_file(source_id)：读取任务已申请的非结构化联创资源。
  • fetch_saved_file(file_path)：读取当前任务此前保存的文件。

基本调用方式

使用前，需要先导入并创建一个 FlyData 对象：

from flydata import FlyData

handler = FlyData()

此后通过该对象调用文件读取方法：

files = handler.load_file("training_data_auto")
path = handler.fetch_saved_file("debug/model.pkl")

同一个脚本中可以重复使用已创建的 handler 对象，无需在每次调用前重新创建。

1. load_file(source_id)

功能

load_file 用于读取任务已申请的非结构化联创资源，例如图片集、文本文件、CSV 文件或其他文件集合。

from flydata import FlyData

handler = FlyData()

files = handler.load_file("training_data_auto")

其中，training_data_auto 是联创资源的调用 ID。

调用完成后，方法不仅会返回描述资源目录结构的字典，还会将字典中指明的目录和文件实际放置到当前沙箱的 data_source/<资源ID>/ 路径下。用户可以根据返回的目录结构确定文件位置，并通过对应路径直接访问文件。

例如，该资源中的文件可以通过以下目录访问：

data_source/training_data_auto/

返回结果

方法返回一个字典，用于描述资源中的目录和文件结构。

假设资源中包含：

training_data_auto/
├── images/
│   ├── p1.png
│   └── p2.png
└── readme.md

返回结果为：

{
    "training_data_auto": {
        "images": {
            "": ["p1.png", "p2.png"]
        },
        "": ["readme.md"]
    }
}

返回结果中：

  • 第一层键是资源 ID。
  • 普通名称键表示子目录，例如 images。
  • 空字符串键 "" 表示当前目录下直接包含的文件。
  • 空字符串键对应的值是文件名列表。

例如：

files["training_data_auto"][""][0]

得到：

readme.md

对应的实际文件路径为：

data_source/training_data_auto/readme.md

下面的代码：

files["training_data_auto"]["images"][""][0]

得到：

p1.png

对应的实际文件路径为：

data_source/training_data_auto/images/p1.png

使用示例

读取文本文件

from flydata import FlyData

handler = FlyData()

handler.load_file("training_data_auto")

with open(
    "data_source/training_data_auto/readme.md",
    "r",
    encoding="utf-8"
) as f:
    content = f.read()

读取图片

from PIL import Image
from flydata import FlyData

handler = FlyData()

handler.load_file("training_data_auto")

image = Image.open(
    "data_source/training_data_auto/images/p1.png"
)

批量读取目录中的图片

from pathlib import Path
from PIL import Image
from flydata import FlyData

handler = FlyData()

files = handler.load_file("training_data_auto")
image_names = files["training_data_auto"]["images"][""]

image_dir = Path("data_source/training_data_auto/images")

images = [
    Image.open(image_dir / image_name)
    for image_name in image_names
]

2. fetch_saved_file(file_path)

功能

fetch_saved_file 用于读取当前任务此前保存的文件，例如模型文件、日志、图片或中间计算结果。

from flydata import FlyData

handler = FlyData()

path = handler.fetch_saved_file("debug/model.pkl")

file_path 是文件在当前任务存储空间中的相对路径。

路径的第一级目录为：

  • debug：调试过程保存的文件。
  • production：生产过程保存的文件。

例如：

debug/model.pkl
debug/logs/20260427.txt
production/images/p1.png

返回结果

方法会将指定文件实际放置到当前沙箱的 fetched_files/ 目录下，并返回该文件的可访问路径。用户可以直接将返回路径传入 open、joblib.load、Image.open 等文件读取函数。

例如：

path = handler.fetch_saved_file("debug/model.pkl")
print(path)

返回：

fetched_files/debug/model.pkl

后续可直接将返回路径传入相应的文件读取函数。

使用示例

读取模型文件

import joblib
from flydata import FlyData

handler = FlyData()

model_path = handler.fetch_saved_file("debug/model.pkl")
model = joblib.load(model_path)

读取文本文件

from flydata import FlyData

handler = FlyData()

log_path = handler.fetch_saved_file(
    "debug/logs/20260427.txt"
)

with open(log_path, "r", encoding="utf-8") as f:
    content = f.read()

读取图片

from PIL import Image
from flydata import FlyData

handler = FlyData()

image_path = handler.fetch_saved_file(
    "production/images/p1.png"
)

image = Image.open(image_path)

3. 两个方法的区别

方法 读取对象 文件访问方式
handler.load_file(source_id) 任务已申请的非结构化联创资源 文件位于 data_source/<资源ID>/
handler.fetch_saved_file(file_path) 当前任务此前保存的文件 方法直接返回 fetched_files/ 下的文件路径

使用联创资源时，先调用 handler.load_file。方法会返回目录结构，并将对应文件实际放置在 data_source/<资源ID>/ 下，用户可根据返回结果定位并读取文件。

使用任务此前保存的模型、日志或中间结果时，调用 handler.fetch_saved_file。方法会将文件实际放置在 fetched_files/ 下，并返回可以直接使用的文件路径。
